01 — About

Understanding systems from the inside out

I'm a dedicated Computer Science student at Northern Illinois University, seeking an entry-level software engineering or internship role upon graduation. My strongest work lives close to the metal: I'm eager to apply solid programming skills in C, C++, and Python to a team building real software.

I learn by rebuilding the tools I use every day. Rather than take a language runtime, a shell, or an editor on faith, I've written my own — which is how I picked up scanning and parsing, process control with fork/exec, and raw terminal I/O. That habit is also why I run Linux with Nix/NixOS and manage my own systems.

I'm continuing to grow my expertise in low-level systems, interpreters, and efficient software design, and I'm looking for a team where that curiosity is useful.

02 — Projects

Things I've built from scratch

Three self-directed systems projects. Each one is a command-line tool, so there's no hosted demo — the source is the demo.

C++

Clox

Lox Interpreter

A complete tree-walk interpreter for the Lox language, following Crafting Interpreters. Handles scanning, parsing, AST evaluation, environments, and the runtime end to end.

  • C++
  • Interpreters
  • Parsing
  • AST evaluation
C

Thesh

Basic Unix Shell

A lightweight Unix shell with command execution, piping, redirection, background processes, and built-ins — built directly on fork/exec and signal handling.

  • C
  • Processes
  • Pipes & redirection
  • Signals
C

Ceditr

Terminal Text Editor

A simple terminal text editor built around buffer management, cursor movement, insert/delete, and file I/O — driven by raw terminal mode rather than a UI library.

  • C
  • Raw terminal I/O
  • Buffers
  • File I/O
